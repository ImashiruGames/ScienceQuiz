# 理科暗記ラボ（ScienceQuiz）

中学理科の重要単語を覚えるためのWebアプリ。問題集の「〇〇を□□という」形式の穴埋め問題を、ひらがなで答えるクイズにしている。

- 全25章・361問（空らん364語）
- `index.html` 1ファイルで動く。ビルドやサーバー側の処理はない

## 機能

| モード | 内容 |
|---|---|
| 暗記カード | 問題文の単語が赤い点線でかくれていて、タップで表示・非表示を切り替える |
| テーマ別クイズ | 章をテーマごとに2〜5問へ分け、画面上のひらがなキーボードで空らんをうめる |
| 全問クイズ | 章のテーマ別クイズをすべて解くと解除される。章の全問がランダムに出て、満点なら紙ふぶきの演出が出る |
| 問題をつくる | 範囲（章・テーマ）・問題数・順番（ランダム／順番どおり／間違えた順）を選んで出題する |

## 使い方

`index.html` をブラウザで開く。GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチのルートを指定する。

フォントは Google Fonts から読みこむため、オンラインで使う想定。オフラインでもシステムフォントで動く。

## しくみ

### 問題データ

`index.html` の `<script>` 冒頭にある `CH` 配列が問題データ。章 → テーマ → 問題文の3階層になっている。

```js
{t:"火山と地震", sec:"§9", h:8, groups:[
  {n:"地震の波と大きさ", q:[
    "初期微動を伝える波を[[P波|ぴーは|ぴいは]]という。",
  ]}
]}
```

- `[[表示|読み|別解…]]` が空らんになる。1つめの読みがヒントと正解表示に使われ、2つめ以降も正解として受けつける
- `t` は章の名前、`sec` は教科書の節、`h` は章の色相（HSLのH）

### 学習記録

記録はブラウザの `localStorage`（キー `rika-anki-lab-v1`）に保存する。端末やブラウザが変わると記録は引きつがれない。

問題ごとの間違えた回数・正解した回数は `章番号-テーマ番号-問題番号` をキーにしている。問題を追加するときは、既存の章やテーマの末尾に足すと、これまでの記録の番号がずれない。

### 間違えた順

間違えた回数が多い順に並べ、同じ回数なら正解した回数が少ない問題を先に出す。
